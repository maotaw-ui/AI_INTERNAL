## 📌 About

This project is an AI-made CS2 internal featuring various gameplay and visual customization options.

The project includes a customizable overlay, aim assistance, ESP features and a manual map injector.

The source code is available for anyone interested in exploring the project and its implementation.

## ⚡ Features

| Feature | Description |
|---|---|
| 🎯 Legit Aimbot | Configurable aim assistance |
| 👁️ ESP | Player boxes and visual information |
| ❤️ Health ESP | Player health and armor indicators |
| 🦴 Skeleton ESP | Player skeleton visualization |
| 📏 Distance | Displays player distance |
| 🔫 Weapon Icons | Displays weapon information |
| 🎨 Customization | Custom colors and visual settings |
| 💥 Hitmarker | Hit feedback and sound |
| 📊 Damage Popup | Floating damage indicators |
| 💉 Manual Map Injector | Included manual mapping component |
